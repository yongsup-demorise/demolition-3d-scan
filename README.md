# Demolition 3D Scan — 3D-01
목표: Galaxy S25 Ultra에서 ARCore Raw Depth + Confidence를 읽어 실시간 3D Point Cloud 표시.

## Android Studio
1. 이 폴더를 Open 합니다.
2. Gradle Sync가 끝날 때까지 기다립니다.
3. S25 Ultra에서 개발자 옵션 > USB 디버깅을 켭니다.
4. USB 연결 후 Run ▶ 을 누릅니다.
5. 카메라 권한 허용 후 천천히 주변을 비춥니다.

화면 상단에 `Raw Depth 정상 · 포인트 N개`가 나오고 녹색 점들이 보이면 3D-01 성공입니다.
